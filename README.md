# مولّد منشورات التقليب — النسخة v2

مجموعة ملفات موقع Netlify جاهزة: تُدخل اسم المنتج، يكتب الذكاء الاصطناعي النص ويختار الألوان، ثم تُرسم ٤ شرائح ١٠٨٠×١٠٨٠ داخل المتصفح.

---

## ١) الملفات

```
carousel-site/
├── index.html                  ← الواجهة + منطق التوليد والتحميل
├── engine.js                   ← محرّك الرسم (١٤ شكلًا + ٤ تركيبات)
├── netlify.toml                ← إعدادات النشر والرابط المختصر
└── netlify/
    └── functions/
        └── generate.js         ← دالة السيرفر (Groq API) — المفتاح هنا فقط
```

> لا يوجد build ولا npm. نشر مباشر.

---

## ٢) النشر على Netlify

**الطريقة الأسهل (سحب وإفلات):**
1. افتح <https://app.netlify.com/drop>.
2. اسحب مجلد `carousel-site` كاملًا.
3. انتهى — الموقع يعمل.

**أو عبر Git:**
1. ارفع الملفات إلى مستودع.
2. أنشئ موقعًا جديدًا واختر المستودع.
3. Build command: اتركه فارغًا. Publish directory: `.`.

---

## ٣) متغيّرات البيئة (مهمة)

من Netlify: **Site configuration → Environment variables**

| المتغيّر | مطلوب | القيمة |
|---|---|---|
| `GROQ_API_KEY` | نعم | مفتاحك من <https://console.groq.com/keys> |
| `GROQ_MODEL` | لا | الافتراضي `openai/gpt-oss-120b` |

بعد الإضافة: **Deploys → Trigger deploy → Clear cache and deploy**.

## ٤) التشغيل محليًا (اختياري)

الواجهة تحتاج الدالة، لذلك لا تفتح `index.html` مباشرة. استخدم Netlify CLI:

```bash
npm i -g netlify-cli
netlify dev
```

ثم افتح العنوان الذي يظهر (عادة `http://localhost:8888`).

## ٥) كيف يعمل التصميم

- `engine.js` يرسم ٤ شرائح، كل شريحة بتركيب مختلف:
  1. **الغلاف** — واحد من ١٤ شكلًا (قوس، انقسام، مجلاتي، شريط، دائرة، شبكة، موجة، تذكرة، إطار مائل، مائل، نقاط متدرجة، بولارويد، زوايا، صورة كاملة).
  2. **الشرح** — صورة أعلى/جانب + عنوان ونص.
  3. **الفوائد** — قائمة مرقّمة بفواصل.
  4. **الدعوة** — لوحة لونية كاملة أو بطاقة.
- الألوان تُهذَّب تلقائيًا: تشبّع محدود، تباين مضمون، ونص فاتح/غامق حسب الخلفية.
- العناوين تُوزَّع على الأسطر بتوازن، ويتم تصغير الخط تلقائيًا حتى يدخل النص كله دون قص.
- الصور: أفقية تملأ الإطار، رأسية تُعرض كبطاقة على خلفية ضبابية من الصورة نفسها، وبدون صورة تُرسم أشكال بديلة.

**لإضافة شكل جديد:** أضف دالة في `HERO` داخل `engine.js` بنفس التوقيع `(ctx, p, slide, img)`، ثم أضف اسمه إلى `MOTIFS` في `engine.js` **و** في `generate.js` (وقائمة `MOTIF_HINT`).

**لتغيير الخط:** عدّل `FONT` في `engine.js` ورابط Google Fonts في `index.html` (يُفضّل أوزان ٤٠٠/٥٠٠/٧٠٠/٨٠٠).

## ٦) تحسينات الـ API في هذه النسخة

- مهلة ٢٠ ثانية على طلب Groq (لا تعليق).
- تنظيف وتحقق من كل حقل قبل الرسم (ألوان HEX، شكل مسموح، أطوال النصوص).
- `max_tokens` من ٢٠٠٠ إلى ١٢٠٠ وبرومبت أقصر (أسرع وأقل تكلفة).
- تجنّب تكرار آخر شكل بين الطلبات.
- حد ١٢ طلبًا/دقيقة لكل IP.
- كاش في المتصفح لنفس المدخلات + زر «تنويع التصميم» يغيّر الشكل محليًا بدون أي طلب.
- رسائل أخطاء عربية (٤٠١/٤٢٩/٥٠٤...).
